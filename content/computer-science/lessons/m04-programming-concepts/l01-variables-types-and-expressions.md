# Variables, Data Types and Expressions

Imagine you are standing in a large, quiet warehouse filled with thousands of empty cardboard boxes. To organize the space, you use a marker to write a unique name on the outside of each box, such as score or player name. Inside the box, you place a specific item, like the number ten or the word champion. In the world of programming, this is exactly how we manage information. While our previous lesson explored how an operating system allocates memory and manages the hardware of the computer, now we are moving inside the programs themselves to see how they keep track of the data they process.

A variable is a named container for a piece of information. To use a variable, you must first initialize it, which means you give it a name and assign it an initial value. If you declare a variable but do not assign it a value, it remains uninitialized or undefined. This is dangerous because the computer might contain leftover data from a previous task in that memory space, leading to unpredictable results. By assigning an initial value, you ensure the program starts with a known, safe state. Once initialized, you can change the value stored in that box later as your program runs. In contrast, some values are constants or literals. These are fixed values, like the number five or the word hello, which cannot be changed after they are created.

A computer needs to know what kind of information is inside those boxes to handle them correctly. This is where data types come in. A data type defines the nature of the data and what operations you can perform on it. For instance, we use an integer type for whole numbers. If you need to store a measurement with a decimal point, you would use a floating-point type. Programs also handle text, which we call a string. A string is a sequence of characters treated as a single unit. There are also logical types that hold only one of two values, representing a state of true or false.

Sometimes, you may need to treat a value of one type as another. This is called type conversion or casting. For example, you might have a number stored as a string, such as the digits one, two, three, and you need to convert it into an integer so you can perform mathematical calculations. Casting tells the computer to produce a value of the new type that stands for the same information. Turning the text one, two, three into the number one hundred twenty-three, for example, means reading each character and building the matching number, which is stored with a completely different pattern of bits.

Once we have stored values in variables, we combine or transform them using expressions. An expression is a combination of values, variables, and operators that results in a new, single value. When you write complex expressions, the computer follows rules of operator precedence and associativity. Precedence determines which operations happen first. For example, multiplication is usually performed before addition. If two operators have the same precedence, associativity determines the order, usually moving from left to right. This ensures that the computer always reaches the same result for a given set of inputs.

Let us walk through an example. Suppose you initialize a variable named price to twenty and a variable named tax to two. You create an expression that adds price and tax together. The computer looks up the value in the price box, looks up the value in the tax box, performs the addition, and produces the result of twenty-two. You can then assign this result to a new variable called total. Expressions can be simple or quite complex, but they always follow these predictable rules to reach a final answer.

By naming our data, categorizing it by type, and using expressions to manipulate it, we build the foundation for all software. We are no longer just moving bits around; we are managing meaning. Once we understand how to store and combine these simple pieces of information, we can start to teach the computer how to make choices based on the results we calculate. In our next lesson, we will look at how to use these variables and expressions to control the flow of a program through conditionals and branching, allowing the software to act differently depending on the data it receives.

## Key ideas

- A variable is a named container that must be initialized with a value to avoid the risks associated with uninitialized memory.
- Data types categorize information and determine which operations are valid, while casting allows a programmer to convert data from one type to another.
- Constants or literals represent fixed values that cannot be changed, whereas variables allow for the storage and updating of data throughout the program.
- Expressions combine variables and values using operators, with precedence and associativity rules ensuring that calculations are performed in a consistent, predictable order.
