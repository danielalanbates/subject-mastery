# What a Function Is

Imagine you step into a parking garage where the automated fee system charges a fixed rate based on how many hours you stay. If you park for two hours, the machine demands a specific payment. If you park for five hours, it demands another. It never happens that feeding the machine a ticket for three hours spits out two different prices at the same time. Every single valid length of time you input corresponds to exactly one price on the screen. That reliable, single-minded rule is the heart of what mathematicians call a function. In our last module, we traced lines on a grid using equations like y equals two x plus three, observing how points line up. Now, we pull back the curtain on those relationships to see them as grand input-output machines.

A function is a formal rule that takes an input, assigns it to a process, and yields exactly one output. We give names to these rules, most often using the letter f, or sometimes g or h. To write out this relationship, we use function notation. Instead of writing y equals, we write f of x equals. Here, f is the name of the rule, and x inside the grouping parentheses is the input, representing whatever number we choose to feed into our machine. In this relationship, the input variable x is also known as the independent variable, because we are free to choose any valid number for it. The resulting output value, represented by f of x, is called the dependent variable, because its final value relies entirely on whatever number we chose for the input. When we read aloud f of x equals three x plus two, we are saying that our rule is named f, operating on the independent variable x, and its action is to take our input, multiply it by three, and then add two to produce the dependent output.

Let us evaluate this function using an actual number. Suppose our input x is four. We substitute four into the formula everywhere we see an x. We multiply three times four, which gives twelve, and then we add two, resulting in fourteen. We write that f of four equals fourteen. Notice the strict rule of uniqueness: four can only ever produce fourteen under this specific rule. An input is never allowed to split and wander off to two different outputs at once. If you plug in four and get both fourteen and nineteen, you are no longer looking at a function.

Functions do not live solely in algebraic formulas. They appear in tables and verbal descriptions as well. Imagine a table listing months of the year alongside the number of days in each month for a non-leap year. January pairs with thirty-one, February with twenty-eight, and March with thirty-one. Even though March and January share the same output of thirty-one days, each month input points to one and only one output. That table describes a valid function. A verbal description can do the same, such as the rule that assigns every living person their exact current age in years. You have one age right now, not two.

When we describe these relationships on a coordinate plane, the layout of the points or curves tells us immediately whether we are looking at a function. We use what is called the vertical line test. Imagine sweeping an imaginary vertical straight line across the coordinate plane from left to right. If that vertical line ever intersects the curve at two or more locations simultaneously, the description fails the test. It fails because touching two points at the same horizontal location means a single input has produced two different outputs, which violates our core definition. A circle on a coordinate plane, for instance, fails the vertical line test because a vertical line can strike its top half and its bottom half at the same time. A standard line sloping upward or a U-shaped parabola passes easily, because every vertical line slices through the curve at precisely one spot.

Understanding how inputs map to outputs opens the door to measuring the exact breadth of what a function is allowed to swallow and what it manages to produce. As we move forward, we will investigate the full collection of permitted inputs and the resulting outputs, as well as how functions can be broken into pieces to describe changing rules.

## Key ideas
- A function is a rule that assigns each input value to exactly one unique output value.
- The input is called the independent variable, while the output value is called the dependent variable because it relies on the input.
- Function notation, written as f of x, names the rule and identifies the input variable inside the grouping parentheses.
- Evaluating a function requires substituting a given number for the input variable and carrying out the arithmetic step by step.
- The vertical line test proves that a relation represents a function if and only if no vertical line intersects the curve more than once.
