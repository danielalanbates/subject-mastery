# Inverse Functions

Imagine you are encoding a secret message by shifting every letter of the alphabet forward by three steps. To read the message later, you need to reverse that exact operation, shifting every letter backward by three steps to recover the original text. In mathematics, undoing an operation is the core idea behind an inverse function. In our last lesson, we combined and composed functions to build intricate new relationships. Today, we turn that process around, asking when a function can be completely undone, how to find its reverse, and how inputs and outputs swap between them.

Not every function can be undone. Suppose you have a function that squares any input you give it, so the input two gives four, and the input negative two also gives four. If you try to run this process backward from the output four, you hit a barrier because you cannot tell whether the original input was two or negative two. A function can only be inverted if every output comes from one and only one input. Mathematicians call this property being one-to-one. In spoken terms, a function is one-to-one if no two distinct inputs ever produce the same output.

When a function is one-to-one, finding its inverse is remarkably direct. Because the function maps inputs to outputs, its inverse simply swaps them back. This means an essential property emerges naturally: the domain of the original function becomes the range of its inverse, and the range of the original function becomes the domain of the inverse. Let us walk through a clear example using the function f of x equals two times x plus six. Here, the function takes an input, multiplies it by two, and adds six. To find the inverse function, we first write out the relationship as y equals two times x plus six. Next, we swap the roles of x and y to represent reversing the process, giving us x equals two times y plus six. Now, we solve this new equation for y. Subtract six from both sides, so x minus six equals two times y. Then, divide both sides by two, giving y equals the quantity x minus six all divided by two. This resulting expression is our inverse function. We denote the inverse function using a superscript negative one on the function name, so we write f inverse of x, which denotes the inverse function itself and is never an exponent of negative one.

How can we be certain this new function truly undoes the original one? We check our work using function composition. If we take our original function and plug the inverse into it, or take the inverse and plug the original function into it, the net result must simplify down to just x, bringing us right back to where we started. Let us test our example. We take the original function evaluated at our inverse, which is two times the quantity x minus six divided by two, all plus six. The multiplication by two and the division by two cancel each other out, leaving us with x minus six plus six. That simplifies neatly to just x. Checking it the other way confirms the same balance, verifying that our inverse is correct.

There is also a striking geometric way to view this relationship. If you plot a function and its inverse on the same coordinate plane, their curves are exact mirror images of each other across the diagonal line y equals x. Because finding an inverse literally swaps every x coordinate with its corresponding y coordinate, every point on the original curve at coordinates r and s reflects across that diagonal line to become the point s and r on the inverse curve. This graceful symmetry gives us a powerful way for understanding how inverse relationships behave. As we move forward to our next lesson on quadratic functions and the vertex, we will explore how restricting the domain of certain curves lets us invert them even when they are not initially one-to-one.

## Key ideas
- An inverse function undoes the original operation by reversing the direction of the mapping between inputs and outputs.
- A function has an inverse only if it is one-to-one, meaning every output corresponds to a single, unique input.
- The domain of the original function becomes the range of its inverse, and the range of the original function becomes the domain of the inverse.
- The notation f inverse of x denotes the inverse function, not an exponent of negative one.
- To find an algebraic inverse, swap the input variable and output variable in the equation and solve for the new output variable.
