# Intuitive Limits and Tables

Imagine you are walking along a mountain path that is interrupted by a sudden, narrow chasm. You cannot step onto the empty space where the path used to be, but you can walk right up to the very edge of the cliff from either side. Even if the bridge is missing, you can look at the height of the path as you get closer and closer to the gap. If the path on the left leads to a height of five thousand feet, and the path on the right also leads to that same height of five thousand feet, you can confidently say that the path was intended to be at that specific elevation. This is the heart of the concept of a limit.

The development of these ideas was marked by a bitter priority dispute between Sir Isaac Newton and Gottfried Wilhelm Leibniz. While they both arrived at the core truths of calculus independently, they used different languages to describe them. Newton used a notation involving dots over variables, while Leibniz developed the notation we often use today, such as the d y over d x for derivatives and the elongated s for integrals. Despite their personal conflict, we rely on the foundations they both laid.

In calculus, we often deal with situations where we cannot calculate a value exactly at a specific point, such as when a formula involves dividing by zero. Since the function is undefined at that spot, we do the next best thing. We look at the behavior of the function as we get closer and closer to that point. We call this the limit. Formally, we say the limit as x approaches the constant c of f of x equals the value L. This means that as the input x gets arbitrarily close to the number c, the output f of x gets arbitrarily close to the specific value L.

For a limit to exist at a point, the function must approach the same value from both directions. If the path from the left leads to one height and the path from the right leads to a different height, the limit does not exist. Agreement between both sides is essential. One of the most intuitive ways to estimate a limit is by using a numerical table of values. This is essentially a zoom in method. If we want to know what happens to a function as x approaches one, we can test values like zero point nine. Then we can test zero point nine nine, and finally zero point nine nine nine. These are values approaching one from the left. We must also check values from the right, such as one point one, one point zero one, and one point zero zero one. If the outputs for all these numbers head toward the same destination, we have found our limit.

Let us try this with a concrete example. Consider a function where f of x equals the quantity x squared minus one, divided by the quantity x minus one. If you try to plug in x equals one directly, you run into a problem. One squared minus one is zero, and one minus one is zero. You end up with zero divided by zero, which is undefined. To find the limit as x approaches one, we build a table.

Starting from the left, let us plug in zero point nine. Zero point nine squared is zero point eight one. If we subtract one, we get negative zero point one nine. For the denominator, zero point nine minus one is negative zero point one. When we divide negative zero point one nine by negative zero point one, the result is one point nine. If we move closer and plug in zero point nine nine, the output becomes one point nine nine. If we plug in zero point nine nine nine, we get one point nine nine nine. It appears the function is heading toward the number two.

Now we must check from the right side. Let us plug in one point one. One point one squared is one point two one. Subtracting one gives zero point two one. The denominator is one point one minus one, which is zero point one. Dividing zero point two one by zero point one gives us two point one. If we plug in one point zero one, we get two point zero one. Since both sides are converging on the same value, we can conclude that the limit as x approaches one of our function is two.

While tables are excellent for building intuition, we must use them with caution. A table only shows us a few snapshots of a function. If a function is extremely volatile, a table might mislead us. Consider the function f of x equals the sine of the quantity one divided by x. As x approaches zero, the fraction one divided by x grows larger and larger. This causes the sine function to oscillate, or swing back and forth, between negative one and positive one with increasing speed. If you only look at specific points in a table, you might miss this wild behavior. You might even pick points that all happen to result in zero, which would trick you into thinking the limit is zero. Because the function never settles on a single value as it approaches the center, the limit does not exist.

The key takeaway is that a limit is about the journey, not the destination. It does not matter if the function actually exists at the point c. What matters is the value the function approaches as it gets closer to c from both sides.

## Key ideas

- A limit describes the value a function approaches as the input gets closer and closer to a specific point from both the left and the right.
- For a limit to exist, the values approaching from the left side must equal the values approaching from the right side.
- To estimate a limit numerically, create a table of values that approach the target input from both directions to see if the outputs converge on a single number.
- Tables provide strong intuitive evidence for a limit, but they can be misleading if a function oscillates rapidly between the chosen data points.
- Isaac Newton and Gottfried Wilhelm Leibniz independently developed calculus and created the different notations we still use to describe derivatives and integrals today.
