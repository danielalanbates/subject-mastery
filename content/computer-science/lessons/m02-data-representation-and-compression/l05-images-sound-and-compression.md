# Images, Sound and Compression

Imagine you are looking at a high-definition photograph of a sunset. To your eyes, it is a seamless blend of brilliant oranges, deep purples, and soft pinks. But to a computer, that image is a massive grid of tiny, individual squares called pixels. Each pixel is a single, solid color tile. To represent this digitally, the computer assigns a specific numeric value to each pixel. The number of bits used to represent the color of a single pixel is called color depth. A higher color depth allows for a wider range of colors, but it also increases the storage space required for each pixel. The total uncompressed size of an image is calculated by multiplying the number of pixels by the color depth.

If images capture space, sound captures time. A musical note travels through the air as a smooth, continuous wave of pressure. A computer cannot store a physical wave, so it uses a process called sampling. It measures the height of that wave at specific moments every second. This frequency of measurement is the sampling rate. The audio bit depth, or bits per sample, determines the dynamic range, or the difference between the quietest and loudest sounds the system can record. Multiplying the sampling rate by the bit depth, the number of channels and the length of the recording in seconds gives the uncompressed size of an audio file.

In both cases, we face a trade-off between quality and size. Increasing resolution or sampling rates makes the digital file more accurate, but it also consumes more memory. This is where compression becomes essential. Compression is the art of representing the same information using fewer bits. We categorize these techniques into two types: lossless and lossy.

Lossless compression is like packing a suitcase using a precise folding technique. You rearrange items to take up less space, but when you unpack them, everything is exactly as it was. Simple methods replace a run of repeated values, such as forty white pixels in a row, with a single count and value. More advanced techniques like Huffman coding or the Lempel-Ziv-Welch algorithm look for statistical redundancies to shrink files. These are perfect for text or medical images where every detail must be preserved. Common lossless formats include the portable network graphics format for images and the free lossless audio codec for sound.

Sometimes, we are willing to sacrifice detail to save space. This is where lossy compression excels. Lossy techniques identify information that human senses are unlikely to notice and discard it. For example, our eyes are sensitive to brightness but less sensitive to subtle changes in color. Algorithms often use chroma subsampling, which reduces the resolution of color information while keeping brightness data intact. In audio, lossy compression uses a psychoacoustic model to remove frequencies that are masked by louder sounds, meaning we simply cannot hear the difference.

These methods often rely on transform coding, such as the discrete cosine transform used in the joint photographic experts group format for images or the modified discrete cosine transform used in the moving picture experts group audio layer three format. These processes convert data into a mathematical form where less important details can be quantized or rounded off. If you compress a file too much, you will see or hear artifacts. In images, this might appear as blocking or ringing around edges. In audio, you might hear a pre-echo, where a faint sound occurs just before a sharp transient like a drum beat.

Engineers constantly refine these algorithms to balance our desire for high-quality media with the physical limits of storage and network speeds. Whether it is a photograph or a symphony, the goal is to represent the analog world as a sequence of bits that we can manipulate, store, and transmit efficiently. By understanding how we translate these complex signals into numbers, you have built a foundation for how computers manage information. Now that we understand how data is represented and packed into bits, we are ready to look at how computers process that data to make decisions. ## Key ideas

- Uncompressed image size is the number of pixels times the color depth, and uncompressed audio size is the sampling rate times the bit depth, times the number of channels, times the length in seconds.
- Lossless compression, such as Huffman coding or the Lempel-Ziv-Welch algorithm, preserves all original data, making it ideal for files where precision is mandatory.
- Lossy compression achieves significant file reduction by using psychoacoustic or visual models to discard information that is less perceptible to human senses.
- Common lossy formats like joint photographic experts group and moving picture experts group audio layer three use transform coding and quantization, which can introduce artifacts like blocking or pre-echo at high compression levels.
