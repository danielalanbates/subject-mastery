# Continuity and the Intermediate Value

Imagine you are driving a car and you look down at your speedometer. As you accelerate from forty miles per hour to sixty miles per hour, your car must, at some point, travel at exactly fifty miles per hour. You do not simply teleport from one speed to the next. This intuitive sense of connectedness is the heart of what mathematicians call continuity. In our last lesson, we used the Squeeze Theorem to pin down difficult limits by trapping them between two known functions. Now, we use the concept of the limit to provide a rigorous definition for a function that is truly unbroken.

We say a function f of x is continuous at a specific point, let us call it the constant c, if the graph does not have a hole, a jump, or a vertical asymptote there. To be mathematically precise, we require three specific conditions to be met at that point. First, the function must actually be defined at c. If there is a hole in the graph where c should be, the function is not continuous. Second, the limit of the function as x approaches c must exist. This means the left-hand limit and the right-hand limit must agree, ensuring there is no vertical jump or wild oscillation. Third, and most importantly, that limit must be exactly equal to the value of the function at c.

If any of these three conditions fail, the function is discontinuous at that point. You can visualize a continuous function as one you can draw on a piece of paper without ever lifting your pencil. Most of the functions you have encountered so far, such as polynomials, sine, and cosine, are continuous everywhere. Rational functions are also continuous, except at the specific points where their denominators equal zero. Isaac Newton and Gottfried Wilhelm Leibniz, who famously and bitterly disputed who first invented calculus, relied on curves being unbroken without defining continuity precisely. The definition we just gave came in the early nineteenth century, from Bernard Bolzano and Augustin-Louis Cauchy.

This leads us to one of the most powerful tools in calculus: the Intermediate Value Theorem. It sounds formal, but it matches our earlier intuition about the car speedometer. Suppose we have a function f that is continuous on a closed interval from the left endpoint p to the right endpoint q. If we know the value of the function at p and the value at q, then the function must take on every single value between f of p and f of q at least once. If a continuous path starts at a height of five and ends at a height of ten, it must cross the height of seven at some point along the way.

One of the most practical applications of this theorem is finding roots. A root is simply an x-value where the function's output is zero. Often, we encounter equations that are impossible to solve using basic algebra. In these cases, the Intermediate Value Theorem allows us to prove a solution exists even if we cannot see it immediately. If a continuous function is negative at one point and positive at another, it is a mathematical certainty that the function must cross the x-axis somewhere in between.

Let us walk through a concrete example. Suppose we have the function f of x equals x cubed, plus x, minus one. We want to know if there is a number x that makes this function equal zero. Since this is a polynomial, we know it is continuous everywhere. Let us test some small whole numbers to see if the sign of the output changes. If we plug in zero for x, we get zero cubed plus zero minus one, which equals negative one. If we plug in one for x, we get one cubed plus one minus one, which equals positive one.

Because the function is continuous and the value at zero is negative while the value at one is positive, the Intermediate Value Theorem guarantees that there is at least one number between zero and one where the function is exactly zero. We might not know the exact decimal value of that root yet, but we have narrowed its location down to a small window. By testing the midpoint of that interval, such as one-half, we could narrow the window even further. This process of repeatedly halving the interval is a common way to approximate square roots and other irrational numbers.

Consider the function f of x equals x squared minus two. If we plug in one, we get negative one. If we plug in two, we get positive two. Since the function is continuous, it must equal zero somewhere between one and two. That specific value is the square root of two. We have just used continuity to prove the existence of an irrational number. This ability to bridge the gap between discrete points and a continuous range is what makes calculus so much more powerful than simple algebra. Now that we understand how functions behave over finite intervals, we can turn our attention to how they behave as x grows larger and larger without bound, leading us to the study of limits at infinity and horizontal asymptotes.

## Key ideas

- A function is continuous at a point if the function is defined there, the limit exists there, and the limit equals the function value.
- The Intermediate Value Theorem states that a continuous function on a closed interval will take on every value between the outputs of its endpoints.
- We can use the Intermediate Value Theorem to prove the existence of roots by finding an interval where the function changes from negative to positive.
- Polynomials, sine, and cosine are continuous everywhere, while rational functions are continuous everywhere their denominators are not zero.
- Continuity allows us to move from observing individual data points to understanding the unbroken behavior of a mathematical system.
