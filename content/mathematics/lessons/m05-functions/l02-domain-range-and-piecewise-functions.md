# Domain, Range and Piecewise Functions

Imagine you are managing the water level of a reservoir. You can control how much water flows inward, but the basin has physical limits. It cannot hold a negative amount of water, and if the volume exceeds ten thousand gallons, water spills over the dam. The rules of the container dictate what you can put in and what can actually come out. Functions behave in much the same way. In our last lesson, we saw that a function is a rule assigning to each input exactly one output. Today, we examine the boundaries of those inputs and outputs, known respectively as the domain and the range, and we look at functions that change their rules halfway through.

Let us start with domain. The domain of a function is the complete set of all allowed inputs. When we evaluate an expression, certain numbers might break the mathematics. Consider the function where f of x is defined as one divided by the quantity x minus three. If you try to input the number three, the denominator becomes zero. Division by zero is undefined, so three is banned from the domain. Every other real number is completely safe. In interval notation, we describe this allowed set as every real number except three. We write this aloud as the union of the open interval from negative infinity to three, and the open interval from three to infinity.

Another major restriction comes from even roots, such as square roots, because real numbers cannot yield negative results when multiplied by themselves an even number of times. Consider the function where f of x equals the square root of the quantity x minus two. If we try to input the number one, the expression inside the square root becomes one minus two, which is negative one. The square root of negative one is not a real number. For example, if we test the number six, six minus two is four, and the square root of four is two, which works perfectly. Therefore, our input x must be greater than or equal to two. In interval notation, the domain is every number from two to infinity, including two. Whenever you look for a domain, ask yourself what numbers would cause a square root of a negative quantity or a division by zero, and exclude them.

The range, on the other hand, looks at the output side of the machine. It is the complete set of all values that the function actually produces. Consider the simple squaring function where f of x equals x squared. You can input any real number you like, positive or negative or zero, meaning the domain is all real numbers. But when you square any real number, the result is never negative. Zero squared is zero, and negative two squared is positive four. Therefore, the possible outputs start at zero and stretch upward forever. In interval notation, the range is every number from zero to infinity, including zero.

Sometimes a single rule is not enough to describe a real world situation. Think about how a shipping company charges for a package. They might charge a flat fee of five dollars for any weight up to two pounds, but for any weight above two pounds, they charge an extra three dollars for each additional pound. Or consider a progressive income tax schedule where different tax brackets apply to different portions of earnings. Mathematicians handle these situations using piecewise functions, which are functions defined by different algebraic formulas on different intervals of the domain.

Let us build a concrete piecewise function. Suppose our function f of x uses the rule two times x whenever the input x is less than or equal to one. But for any input x greater than one, the function switches to the rule x plus three. To find the value of this function at a specific input, we first check which interval our input belongs to. If we want to evaluate f of zero, we see that zero is less than or equal to one, so we use the first rule. Two times zero is zero, so f of zero equals zero. If we want to evaluate f of four, we look at our intervals and see that four is greater than one, so we use the second rule. Four plus three is seven, so f of four equals seven.

When examining the behavior of a piecewise function, we must track how the rules shift across the domain. For input values less than or equal to one, the rule two times x produces every real number up to and including two. At the exact input of one, the first piece ends at an output value of two. As the input steps just past one into the second rule, x plus three, the output immediately jumps to values just above four and continues growing upward without bound. This means the overall domain of our piecewise function includes every real number, while the range splits into two distinct sets of outputs, covering all numbers up to two, and then resuming at any value strictly greater than four to infinity. As we move forward into our next lesson, we will build on these structural insights to explore how function values behave overall, tracking where they rise and fall and how fast those changes happen.

## Key ideas
- The domain of a function is the complete set of all allowed inputs, while the range is the complete set of possible resulting outputs.
- Interval notation describes sets of numbers by stating their endpoints and whether those endpoints are included or excluded.
- Division by zero and even roots of negative numbers are the primary restrictions that limit the domain of a function in the real number system.
- Piecewise functions apply different mathematical rules to different intervals of the domain, allowing us to model complex real world schedules and rates.
- The range of a piecewise function is determined by collecting the individual output sets produced by each formula across its respective domain interval.
