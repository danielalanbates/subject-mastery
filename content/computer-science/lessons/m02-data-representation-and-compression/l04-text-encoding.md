# Text Encoding

Imagine you are trying to send a secret message to a friend using only a row of light switches. You can turn each switch either on or off. If you want to communicate something complex, like a poem or a shopping list, you need a shared rulebook. You and your friend must agree that a specific pattern of switch positions represents a specific letter. In our previous lesson, we looked at how computers represent fractions and floating point numbers using these same binary patterns. Today, we turn our attention to the human side of data: how we translate the alphabet, punctuation, and even the nuances of global languages into that same binary language of ones and zeros.

The most fundamental way to represent text is to assign each character a unique number. Think of it like a massive library index where every letter is assigned a seat. In the early days of computing, the American Standard Code for Information Interchange became the dominant system. It used seven bits to represent characters, which allowed for one hundred twenty-eight unique combinations. This was plenty for the English alphabet, numerals, and basic control characters like a carriage return or a tab. Because seven bits is just enough to cover the basics, the system was efficient for the memory-constrained machines of the mid-twentieth century. However, it had a major limitation. It was designed primarily for American English, leaving no room for the accented characters of European languages, let alone the thousands of symbols used in scripts like Chinese, Japanese, or Arabic.

As computers became global, the seven-bit standard proved insufficient. We needed a system that could accommodate the entire world’s writing systems. This led to the development of Unicode. Unicode is a universal character set that assigns a unique number, called a code point, to every character in almost every script humanity has ever used. It even includes historical scripts and modern additions like emoji. Because there are so many characters, we cannot represent them all with just seven or eight bits.

It is important to distinguish between the character set itself and the way we store those characters in computer memory. Unicode defines the unique code point for each character, but we need an encoding scheme to map those code points to actual bytes. The most common scheme is known as Universal Character Set Transformation Format eight-bit, or UTF eight. This is a variable-length encoding. In this system, the computer checks which character it needs to encode and decides how many bytes to use. For standard English letters, which are the most common in many computing contexts, it uses only one byte, keeping the files small and compatible with older systems. If the computer encounters a more complex character, such as a mathematical symbol or a character from a non-Latin script, it automatically switches to using two, three, or even four bytes. This flexibility is brilliant because it keeps data compact when possible but allows for global expression when necessary.

Consider the letter B. In this encoding scheme, it is represented by a single byte, which is a specific pattern of bits. If you were to store a word like cat, the computer would simply store the three unique numbers corresponding to those letters in a sequence. If you were to add an emoji, the computer would recognize that this specific symbol requires more than one byte and would expand the storage for that character accordingly. This process happens instantly and invisibly, allowing us to type in any language or share visual symbols across the internet without ever needing to worry about the underlying mathematics of the bit patterns.

When we store text, we are essentially building a bridge between the physical world of human communication and the logical world of binary electricity. By mapping every letter and symbol to a precise numerical value, we enable computers to process, sort, and display the vast sum of human knowledge. Once we have mastered how text is encoded, we can begin to explore how more complex forms of information—such as the vibrant colors of a photograph or the nuanced frequencies of a musical recording—are distilled into those same reliable patterns of bits.

## Key ideas

- Text encoding is the process of mapping characters to unique numerical values that computers can store as binary patterns.
- The early American Standard Code for Information Interchange used seven bits to represent one hundred twenty-eight characters, which was sufficient for English but limited for global use.
- Unicode is a universal character set that assigns a unique code point to characters from writing systems across the world, while UTF eight is an encoding scheme that maps those points to bytes.
- Variable-length encoding allows computers to use fewer bits for common characters and more bits for complex symbols to balance efficiency and versatility.
