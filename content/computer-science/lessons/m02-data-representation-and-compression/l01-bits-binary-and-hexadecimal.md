# Bits, Binary and Hexadecimal

Imagine you are standing in a dark room with a single light switch. You have only two options: the light is either on, or it is off. This simple choice represents the fundamental way a computer understands the world. In our last lesson, we looked at the history of computing, moving from massive, room-filling vacuum tubes to the compact smartphones in our pockets. Today, we go beneath the screen and the glass to look at the silent, invisible language that powers every calculation those devices perform. That language is built entirely on the concept of the bit.

A bit, which is short for binary digit, is the smallest unit of information a computer can store. Think of it like that light switch. It can exist in one of two states: on or off. We represent these states with the numerals one and zero. Because electricity is either flowing through a circuit or it is not, two states are the most reliable way to design hardware. By grouping these bits together, we can represent complex information. A group of eight bits is called a byte. If a single bit is a light switch, a byte is like a row of eight switches that can be flipped in different combinations to represent a specific value.

To count in binary, we use a base two system. In our everyday decimal system, which is base ten, each position represents a power of ten. The first position is ones, the second is tens, the third is hundreds, and so on. In binary, each position represents a power of two. Moving from right to left, the positions are ones, twos, fours, eights, sixteens, and thirty-twos. To convert the binary number one, zero, one, one into a decimal number, we look at the positions where there is a one. We have one eight, zero fours, one two, and one one. Adding eight plus two plus one gives us eleven.

This binary system is incredibly efficient for a machine, but it is quite cumbersome for humans to read. If you wanted to represent a large number or a color code in binary, you would end up with a very long, confusing string of ones and zeros. This is why computer scientists use a shorthand called hexadecimal. Hexadecimal is a base sixteen system. It uses the digits zero through nine, followed by the first six letters of the alphabet to represent values ten through fifteen.

Because sixteen is two to the power of four, each hexadecimal digit maps perfectly to a group of four binary bits. This makes conversion straightforward. For example, if you have the binary sequence one, one, one, zero, one, zero, zero, one, you can split it into two groups of four. The first group, one, one, one, zero, corresponds to the decimal value fourteen, which is represented by the letter E in hexadecimal. The second group, one, zero, zero, one, is the decimal value nine. Therefore, the binary sequence one, one, one, zero, one, zero, zero, one is simply E nine in hexadecimal.

Using hexadecimal allows programmers and engineers to look at a block of memory and quickly translate it into something readable. It acts as a bridge between the raw, electrical reality of the hardware and the abstract logic that humans use to write software. While we rarely have to perform these conversions by hand in modern development, understanding the relationship between bits, bytes, and hexadecimal is essential. It helps you grasp how data is packed into memory and how computers manage to move vast amounts of information through their internal pathways without losing track of a single digit.

As we continue our exploration of data representation, you will see that these bits are not just used for simple counting. They are the building blocks for every letter in a text file, every pixel in a photograph, and every note in a digital recording. However, before we can begin encoding words or images, we must first learn how computers handle larger numbers and what happens when those numbers grow too large for the space we have allocated to store them. In our next lesson, we will examine the concept of whole numbers and the problem of overflow.

## Key ideas

- A bit is the smallest unit of data in a computer, representing one of two states, while a byte consists of eight bits.
- Computers use binary because it is the most reliable way to represent data using the two states of electrical current, either on or off.
- Binary numbers are converted to decimal by adding the values of each position, where every position represents a successive power of two.
- Hexadecimal is a base sixteen system that serves as a human-readable shorthand for binary, where one hexadecimal digit represents a group of four bits.
